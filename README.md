# FormulaHub

FormulaHub is an English, searchable reference library for mathematics, physics, engineering, chemistry, statistics, and finance formulas. Select any formula, enter values, and calculate an answer instantly.

## Features

- 44 formulas across six disciplines
- Instant search by name, concept, symbol, or category
- Interactive calculator for every formula
- Favorites and light/dark themes
- Responsive layout for desktop and mobile

## Run locally

```bash
cd myapp
npm install
npm run dev
```

## Build

```bash
npm run lint
npm run build
```
